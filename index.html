About Al-Quran Memorizer

🎙️ Audio Vault & Seamless Sync

Audio is streamed directly from your GitHub Releases vault with continuous playback. When in timestamp mode, transitions between verses run seamlessly without media pauses.

000.mp3 is reserved for Bismillahir Rahmanir Rahim and automatically precedes recitations (except Surah 9, At-Tawbah).

🎙️ Fallback Reciters

If an audio file is not found in your vault, it plays Sheikh Abdur-Rahman as-Sudais & Sa'ud ash-Shuraim recitation automatically.

⚡ Memorization Controls

  • Single Chunk Loop (🔁): Repeat an active Ayah or segment continuously.
  • Range Loop (X to Y): Loop any segment of Ayahs within the current Surah.
  • Dual Bookmarking: Bookmark entire Surahs or specific Ayahs from both Verse and Reading modes.
